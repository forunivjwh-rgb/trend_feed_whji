# 저장 파일 (자동으로 고쳐지는 브랜치)

이 브랜치는 GitHub Actions 가 매일 새벽 한 번 자동으로 고친다. 손으로 고치지 않는다.

- `trend.db` — 저장 파일(SQLite 한 파일, 명세 8번). 수집한 글의 제목·링크·출처와 그날의 숫자,
  주제와 점수, 실탐 요약, LLM 사용량이 들어 있다. 본문·자막·댓글 같은 원문은 없다.
- 내려받아 [DB Browser for SQLite](https://sqlitebrowser.org/) 같은 프로그램으로 열어 볼 수 있다.
- 윈도우·맥 컴퓨터에서 돌리기 시작하면 이 파일을 그 컴퓨터의 `data/trend.db` 로 복사해 이어 쓰면 된다.
- 코드와 설명은 `main` 브랜치에 있다.
